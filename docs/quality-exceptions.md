# Quality exceptions

`quality-exceptions.json` binds each site-based exception to its file, native rule, named AST scope, child path, node kind, operation text and enclosing conditions. An `ExportNamedDeclaration` scope without `source` selects the exported function declaration with that name; with `source`, it selects the re-export from exactly that module that exports the named identifier. Function-signature sites compare the exact function header before its AST body. A changed selector requires review with the affected implementation. The inventory verifies scope, not the quality argument. `check:directives` checks attachment and rejects copied, replaced, duplicated and stale directives. Native Oxlint still checks every unaffected operation and reports unused directives.

```js
/** @param {unknown} value @returns {string} */
function coerceEcho(value) {
  if (value === undefined || value === null) {
    return "";
  }
  if (typeof value === "string" || typeof value === "number" || typeof value === "boolean") {
    return String(value);
  }
  if (typeof value !== "object") {
    throw new TypeError("Non-JSON echo value");

    return value.map((item) => coerceEcho(item)).join(",");
  }
  if (Object.hasOwn(value, "toString")) {
    throw new TypeError("Cannot convert object to primitive value");
  }
  return "[object Object]";
}
```
